# Glossary

A personal list of technical English terms I am learning.

- **Kernel**: the core of an operating system.
  Example: "The Linux kernel manages the hardware."

- **Firewall**: a system that blocks unwanted network traffic.
  Example: "The firewall blocks all incoming connections."

- **Server**: a computer that provides services to other computers.
  Example: "The web server hosts the website."

- **Network**: a group of computers connected to share data.
  Example: "All the computers in the office are on the same network."

- **Terminal**: a text window where you type commands to control the computer.
  Example: "I opened the terminal and listed the files."

- **Command**: an instruction that you type in the terminal.
  Example: "The ls command shows the files in a folder."

- **Directory**: a folder in a file system.
  Example: "I created a new directory called practice."

- **Virtual machine**: a computer that runs inside another computer.
  Example: "I installed Ubuntu in a virtual machine."

- **Digital hoarding**: the excessive accumulation of digital files and data.
  Example: "Digital hoarding makes it difficult for users to organize their files effectively."

- **Cloud storage**: remote digital storage accessed via the internet rather than local hard drives.
  Example: "Unlimited cloud storage often encourage s people to save unnecessary files."
